# Porsche Coder

保时捷诊断编码工具 · iOS / Android · 支持多种 OBD 适配器

给保时捷车友的 DIY 诊断编码工具。覆盖 **25 个车型**、**4,588 个模块变体**、**110 万+ 条诊断条目**，支持设码、故障码、特殊功能、数据流、执行器测试等完整诊断功能，另有**模拟模式**可无车离线体验全流程。

## 编码功能

### 设码（刷隐藏/改装）

- **分组导航**：组 → 编码页（大组按 50 条一页，`组名0/组名1/…`）
- **批量视图**：进组即显示每项**当前值**并可直接修改——无论有无分页，体验一致
- **搜索**：跨全量条目搜索（含子分组内容）
- **值类型**：枚举下拉框（如 Coupe/Cabrio/Targa/Turbo/GT）/ 开关 / 数值 / 曲线表
- **独立详情页**：点进参数查看位置、服务、风险

### 备份/恢复

一键备份全部编码到本地存储，随时恢复（恢复走与写入相同的事务保护）。

## 安全

### 写入闸门

写入受**结构性闸门**保护（与主流诊断工具同口径，不设自创拦截）：

1. **只读项拒写**：只读参数拒绝写入
2. **LID 必须存在**：缺 LID 的参数拒绝写入
3. **变更范围检查**：写入值不能超出位宽/值域
4. **回读校验**：写入后回读比对，不一致即报错

写入事务统一加锁（含恢复/批量/编程页），全程「备份 → 写 → 回读」。

### 安全访问（seed/key）

全算法面离线算 key，按模块真实参数路由；无算法分支的模块**明确拒写**（不猜 key、不试错）。

### 风险提示

⚠️ **改错编码可能导致功能异常、故障灯、甚至需要 4S 恢复。**

- 建议先在**模拟模式**体验流程，理解后再上车
- **首次上车只做只读对照**；写入前导出备份，逐项确认当前值/目标值
- **每次只改一项**，改后核对回读
- 涉及安全气囊、制动、转向、变速箱的功能风险极高，请谨慎

## 技术架构

- **前端**：HTML / CSS / JavaScript（esbuild 打包）
- **iOS**：Capacitor 8 + Swift 插件（MFi 外部配件、分享）
- **Android**：Capacitor 8
- **协议**：KWP / UDS 诊断协议（ISO-TP 多帧，按记录服务成帧）
- **数据**：按车型/模块/变体懒加载 JSON（1.4G，运行时按需取）
- **地址/会话**：逐 ECU 原厂进模块帧序与会话表（数据驱动）

## 常见问题

**Q: 为什么扫描不到我的适配器？**
A: 去系统蓝牙设置确认设备已连接。MFi 设备由 iOS 系统持链路，App 需要在系统已连接后才能访问。

**Q: 支持哪些保时捷车型？**
A: 25 个车型全覆盖，从 1990 年代的 964/993 到最新的 Taycan/Panamera YA。详见上方车型表。

**Q: 写入功能安全吗？**
A: 写入受 4 道结构性闸门 + 回读校验保护，安全访问 key 按模块真实参数计算、算不出即拒写。但改编码本身有风险——建议先模拟模式体验，上车先只读对照，每次只改一项、改前备份。

**Q: 没有车能用吗？**
A: 可以。开启模拟模式即可离线体验全部功能。

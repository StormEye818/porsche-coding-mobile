# Porsche Coder

保时捷诊断编码工具 · iOS / Android · 支持多种 OBD 适配器

给保时捷车友的 DIY 诊断编码工具。覆盖 **25 个车型**、**1146 个模块**、**110 万条编码条目**，支持设码、故障码、特殊功能、数据流、执行器测试等完整离线诊断功能。

## 编码功能

### 设码（刷隐藏/改装）

- **分组导航**：一级目录 → 二级子组 → 三级参数详情
- **搜索**：跨全量条目搜索（含子分组内容）
- **值类型**：枚举下拉框（如 Coupe/Cabrio/Targa/Turbo/GT）/ 开关 / 数值
- **当前值**：进模块自动读取并显示
- **独立详情页**：点进参数查看位置、服务、风险，修改后写入

### 规则编码

批量查看和修改多个设码值，支持一次性批量写入。按分组进入，逐级浏览。

### 备份/恢复

一键备份全部编码到本地存储，随时恢复。

## 安全

### 写入闸门

写入受**结构性闸门**保护：

1. **SID 配对检查**：读写服务必须配对（`21↔3B` / `22↔2E` / `1A↔3B`）
2. **LID 必须存在**：缺 LID 的参数拒绝写入
3. **变更范围检查**：写入值不能超出 bitsize 范围
4. **回读校验**：写入后回读比对，不一致报错

### 风险提示

⚠️ **改错编码可能导致功能异常、故障灯、甚至需要 4S 恢复。**

- 建议先在**模拟模式**体验流程，理解后再上车
- **每次只改一项**，改前备份，改后核对回读
- 涉及安全气囊、制动、转向、变速箱的功能风险极高，请谨慎

## 常见问题

**Q: 为什么扫描不到我的适配器？**
A: 去系统蓝牙设置确认设备已连接。MFi 设备由 iOS 系统持链路，App 需要在系统已连接后才能访问。

**Q: 支持哪些保时捷车型？**
A: 25 个车型全覆盖，从 1990 年代的 964/993 到最新的 Taycan/Panamera YA。详见上方车型表。

**Q: 写入功能安全吗？**
A: 写入受 4 道结构性闸门保护，算法已验证。但改编码本身有风险——建议先模拟模式体验，上车时每次只改一项、改前备份。

**Q: 没有车能用吗？**
A: 可以。开启模拟模式即可离线体验全部功能。

# Porsche Coder

保时捷诊断编码工具 · iOS / Android · 支持多种 OBD 适配器

给保时捷车友的 DIY 诊断编码工具。覆盖 **25 个车型**、**4,588 个模块变体**、**110 万+ 条诊断条目**，支持设码、故障码、特殊功能、数据流、执行器测试等完整诊断功能，另有**模拟模式**可无车离线体验全流程。

## 适配器支持 · 通道矩阵

| 平台 \ 接头 | vLinker MS（MFi） | 通用 ELM327 / OBDKey（非 MFi） |
|---|---|---|
| **iOS** | ✅ MFi 外部配件通道（EA，系统持链路） | ❌ **暂不支持**（WKWebView 无 Web Bluetooth、本期未接 CoreBluetooth BLE 插件）——给「暂不支持」人话提示；请用 MFi 版接头或安卓端 |
| **Android** | ✅ 经典蓝牙 SPP（主）/ BLE（备），双通路自动选择 | ✅ SPP / BLE 双通路自动选择 |

- 通道由首页「选择接头类型」× 平台自动分流（iOS×vLinker→MFi；iOS×ELM327/OBDKey→BLE（暂不支持，明确提示）；安卓×任意→蓝牙）。
- MFi 是苹果外部配件协议：**安卓任何路径不触达 MFi**；自检失败按通道给可操作提示（开蓝牙/配对、MFi 系统链路、iOS 非 MFi 暂不支持等）。
- 发现语义两平台一致：**只列已配对/已知设备，不盲扫周围**；手动点选（名称+MAC）→记住→之后直连；禁盲连第一个。
- 传输依赖：iOS MFi 走 app 内 MfiSerial 插件；安卓 SPP 走 `@ascentio-it/capacitor-bluetooth-serial@8.0.1`（MIT）；BLE 走 Web Bluetooth（FFE0/FFE1）——iOS BLE 通路代码已备（记住→直连/选择器同 UX），待接 CoreBluetooth MIT 插件即启用。

连接方式：OBD 适配器 → 手机蓝牙（iOS MFi 由系统持链路）→ 本 App

# 操作流程（小白照做）

## 第 0 步 · 准备清单

| 项 | 说明 |
|---|---|
| **OBD 适配器** | vLinker MS（推荐）/ ELM327 / OBDKey |
| **手机** | iOS 16+ 或 Android 9+ |
| **车** | 点火 ON（仪表亮）、**发动机不启动**；电瓶电压 **≥12V**（App 自检会显示实时电压） |
| **iOS 首装三件事** | ① 设置→通用→VPN与设备管理→**信任开发者证书**；② 系统蓝牙设置里**先配对接头**；③ 免费账号签名 **7 天过期**，过期后用 Mac 重装（见「安装」） |

## 真车全流程

### 1️⃣ 连接自检（每次上车第一件事）

1. 适配器插入 OBD-II 口（主驾膝部附近），**点火 ON、不着车**
2. 打开 App → 首页**选接头类型**（vLinker/ELM327/OBDKey）
3. 点 **「⚡ 连接自检」** → 看日志逐阶段打勾：
   ```
   配件发现 → 会话 → 协议锁定 → 模块探测
   ✅ EA 配件: vLinker MS · SN xxxxx
   ✅ ELM327: ATI / ATRV（实时电压）
   ✅ 协议锁定: ATSP6（CAN 11bit/500k）已锁定
   ✅ 连接就绪 —— 可以选模块读写了
   ```
4. 出现 **「连接就绪」** 才算成功。某阶段卡住？见下方「自检失败排查」

### 2️⃣ 识别车型

- **自动搜索**（推荐）：点「自动搜索」→ 自动读 VIN → 显示**年款 + 车名**（如 `14款 Cayman`）→ 确认
- **手动选择**：车系 → 车型（不确定车型时用这个兜底）

### 3️⃣ 进系统读编码（先只读，别急着写）

1. 系统列表选模块（如 `IC(仪表)`、`ECM/DME(发动机)`）
2. 进 **设码 → 刷隐藏/改装**（或规则编码）
3. 编码页形态：大组按 **50 条一页**（`组名0`/`组名1`…）；**进组直接看到每项当前值**，可直改直显
4. 👉 **首次上车只做只读对照**：把各项当前值与你的预期/参考对照，不动任何值

### 4️⃣ 写入（确认无误后才做）

1. 先 **「备份所有编码」**（出问题随时恢复）
2. 每次**只改一项**：改值 → 写入 → App 自动**回读校验**（不一致会报错）
3. 确认车辆功能正常，再进行下一项

### 5️⃣ 其他功能

| 功能 | 入口 | 用途 |
|---|---|---|
| 故障码 | 系统 → 故障码 | 读取/清除 DTC（清码前先记录） |
| 数据流 | 系统 → 数据流 | 实时测量值 |
| 执行器测试 | 系统 → 执行器 | 驱动/回位（注意机械安全） |
| 特殊功能 | 首页或系统内 | 例程：校准/匹配/初始化（按屏幕提示操作） |
| 恢复 | 设码 → 读取备份编码 | 一键恢复到备份值 |

## 模拟模式（没车也能练）

1. 首页点 **「▶ 模拟模式」**（没接头、没车都能进）
2. **全部车型/系统/功能都可浏览**：自动搜索、进模块、看编码当前值、改值、写入——读写全走**模拟车**，不碰任何真车
3. 推荐用法：
   - 提前把「备份→改一项→写入→回读」的完整流程练一遍
   - 教学演示、熟悉各车型的隐藏功能清单
4. 切回真车：重新选接头类型 → 「连接自检」（App 会自动退出模拟态）

## 自检失败排查

| 现象 | 怎么办 |
|---|---|
| 扫不到适配器 | iOS MFi：系统蓝牙设置确认已连接（MFi 链路由 iOS 持）；安卓：开蓝牙并在系统设置配对接头 |
| 自检发现不到设备 | 先到系统蓝牙设置里**配对**接头（如 OBDLink）再点连接自检；发现只列已配对设备、不扫周围；首次弹列表点选、选错点「换接头设备」 |
| 卡在「配件发现」 | 换 USB 线/重插适配器；iOS 检查「隐私与安全→本地网络」权限；安卓确认蓝牙权限已授予 |
| 协议锁定失败 | 确认点火 ON、电瓶电压 ≥12V；电压低会一切通讯异常 |
| 模块探测无应答 | 车熄火了？电瓶亏电？先看自检日志里的 ATRV 实时电压 |
| iOS 提示不受信任 | 设置→通用→VPN与设备管理→信任开发者证书 |
| 写入报「回读不一致」 | 别重试硬写！记录日志，恢复备份后排查该项 |

## 安全

### 写入闸门

写入受**结构性闸门**保护（与主流诊断工具同口径，不设自创拦截）：

1. **只读项拒写**：只读参数拒绝写入
2. **LID 必须存在**：缺 LID 的参数拒绝写入
3. **变更范围检查**：写入值不能超出位宽/值域
4. **回读校验**：写入后回读比对，不一致即报错

写入事务统一加锁（含恢复/批量/编程页），全程「备份 → 写 → 回读」。

### 安全访问（seed/key）

全算法面离线算 key，按模块真实参数路由；无算法分支的模块**明确拒写**（不猜 key、不试错）。

### 风险提示

⚠️ **改错编码可能导致功能异常、故障灯、甚至需要 4S 恢复。**

- 建议先在**模拟模式**体验流程，理解后再上车
- **首次上车只做只读对照**；写入前导出备份，逐项确认当前值/目标值
- **每次只改一项**，改后核对回读
- 涉及安全气囊、制动、转向、变速箱的功能风险极高，请谨慎

## 常见问题

**Q: 为什么扫描不到我的适配器？**
A: 去系统蓝牙设置确认设备已连接。MFi 设备由 iOS 系统持链路，App 需要在系统已连接后才能访问。

**Q: 支持哪些保时捷车型？**
A: 25 个车型全覆盖，从 1990 年代的 964/993 到最新的 Taycan/Panamera YA。详见上方车型表。

**Q: 写入功能安全吗？**
A: 写入受 4 道结构性闸门 + 回读校验保护，安全访问 key 按模块真实参数计算、算不出即拒写。但改编码本身有风险——建议先模拟模式体验，上车先只读对照，每次只改一项、改前备份。

**Q: 没有车能用吗？**
A: 可以。首页点「模拟模式」即可离线体验全部功能（详见上文「模拟模式」）。

**Q: 一次可以改多个值吗？**
A: 规则编码支持批量改值，但建议**逐项写入并确认回读**——一次全写，出问题时难以定位是哪项引起的。

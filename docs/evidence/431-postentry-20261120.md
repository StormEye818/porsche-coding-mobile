## 1. 【Q1】统一状态机 / 发现与绑定（S0–S1）

### PE-01 ｜ 驱动发现循环：每候选 1 帧探针 + n==0 直绑 + 应答即绑
- **做法（E0/反编）**：`DriveLinksMode_1001` 把探针常量 `0xFF001409`（=`22 14 09`）装入 `sl`；从 `[r0,r8]` 读候选数 n，`cbz r1` 当 n==0 **跳过整个探针循环**直接去绑定；循环体 `send(element[i], 0xFF001409, 1)`（r2=1=每候选只 1 帧）；绑定 `send(0x100359, A, 2)`，入参是**行键 A**（请求键坐标 `0x0030xxxx`/`0xFF60xxxx`）不是 CAN 地址；返回 `uxth(ret)==1` 即绑成功，不看识别串。
- **原始坐标**：`libPORSCHE_LINK.so` VA `0x18f00`（`DriveLinksMode_1001`），关键指令 `0x18f4c`（movw sl,#0x1409）/ `0x18f52`（movt #0xff00）/ `0x18f5e`（ldrb n）/ `0x18f62`（cbz n==0）/ `0x18f80-0x18f8c`（候选循环+send）/ `0x18fe2`（movw r0,#0x1102 补帧）/ `0x18fb2-0x18fbc`（绑定 send 0x100359）。
- **可复核命令**：
  ```bash

    /Users/se818/porsche-coder/tools/disasm-elf.py \
    /Users/se818/porsche-mapper/ref/porche-v24.58/V24.58/libPORSCHE_LINK.so 0x18f00 320
  ```
  实测输出含 `0x18f4c movw sl,#0x1409`、`0x18f62 cbz r1,#0x18f9e`、`0x18f86 movs r2,#1`、`0x18f8c blx r3`。
- **对应实现要求**：连接期 candidate 循环**每候选只 1 帧**，n==0 的 sysId 走直绑（9 个 0x0E 代模块即此，431 原生行为不是缺口）；「选行键」与「选 CAN 地址」分离——地址在连接期 live map 解决，进模块时只按行键发帧确认；绑定判定只看帧回执成败，不靠识别串。

### PE-21 ｜ 1A 识别链与 LID 语义（反编 + GAG）
- **做法**：进模块后逐条单发 KWP 2 字节帧 `1A 9F→87→84→91→92→93→94→95→97→9A`，应答 `5A <LID> <ASCII…>` 取原样字节（strcmp 空间）；连续 3 次无数据早停，不重试。LID 语义：**9F=ECU 识别串（变体名匹配）·84=零件号（变体落定主键）·91=图号·92=硬件件号·93=硬件版本·94=软件件号·95=软件版本·96=认证·97=ISO·9A=供应商·87=序列号**。
- **原始坐标**：GAG rec#41 `1a 9f`/1054 `1a 87`/1013 `1a 84`/1022 `1a 91`/1009 `1a 92`/1012 `1a 93`/1458 `1a 94`/1008 `1a 95`/1003 `1a 9a`；SPECF .rodata `1a 9f`@`0x3e024c`、`1a 87`@`0x3e0375`，SPECF 内部验证链起点 `0x3e036b`（`1a 87 85→1a 87 9f→…→1a 87 93`）。
- **可复核命令**：见 PE-02 GAG 脚本（rec#41=`01 02 1a 9f`）。
- **对应实现要求**：识别循环按此固定链跑；变体落定消费 1A84/92/91/94 件号；留原样字节（不 trim 进键，strcmp 字节精确，含尾空格）。

- **对应实现要求**：NRC 上浮到 UI；禁止「SID 0x12 换 SID 重试」（旧自创恢复已删，coder.js:1541-1542）。
- **反例**：`22 00 28` 被拒后改发 `21 xx` 重试（真实失败场景的正确做法是先按记录选对 SID 而非失败后换）。

### PE-52 ｜ NRC 0x11 / 0x10 / 0x22 / 0x31（逐项归口）
- **做法**：0x11 服务不支持 / 0x10 通用拒绝 / 0x22 条件不满足（点火/车速/电压）/ 0x31 请求超范围（LID/DID 不存在）——均**单发即败、不重试、按记录跳过该项或上浮**；0x31 在核对项里「按记录跳过」，在读写块里「记录失败」。无「换族重试」分支。
- **原始坐标**：`src/coder.js:144-158` NRC 文案表（0x10/11/12/22/24/31/33/35/36/37/72/78/7E/7F）；`RE-FLOWSPEC §3.2.1`（`7F 21 31`=LID 不存在，单发即败）。
- **可复核命令**：`sed -n '143,159p' /Users/se818/porsche-coder/src/coder.js`。
- **对应实现要求**：这些 NRC 统一为「失败上浮 + 不重试」；条件类 0x22 不自动重试等条件满足（E0 无此分支）。
- **反例**：把 0x22 当可重试故障反复轮询；0x31 后自动切到另一 LID 重试。

### PE-53 ｜ NRC 0x35/0x36（钥匙错/超次）不重试
- **做法**：`7F 27 24/35/36` = 钥匙错/请求顺序错/尝试次数超限 → **不重试**（防 ECU 锁计数）；换算法变体由解析链（mode 表→名字分发）在**下一次会话**保证，不在同一次重试。
- **原始坐标**：GAG rec#950（`27 0a`）；`RE-WRITEGATES §2c`（发错 key 才计数，不发 key 不计）；`RE-FLOWSPEC §4.2`。
- **对应实现要求**：key 算不出（非零 seed）时 fail-closed 拒写，绝不猜一个 key 去试（猜错=35→36 锁死）。
- **反例**：用全零 key/默认 key 碰运气解锁。

### PE-54 ｜ NO DATA / 空应答（静表 + 反编）
- **做法**：空应答/NO DATA = 读失败（不假成功）；探测阶段 = 该候选死，换下一候选；识别链 = 该 LID 计 miss，3 miss 截断链。**NO DATA 绝不等于「车上没装/全空正确」**。
- **原始坐标**：`RE-FLOWSPEC §5`；`AUDIT-PROTOCOL §⑦`（空响应抛错已对齐）；`PE-01` 探针 `cbz`/候选死分支。
- **对应实现要求**：空响应一律报错/记候选死；G-4 判据「全 NO DATA」只能记「待 E0 复核」，不得当收口理由。
- **反例**：把某模块全部读取 NO DATA 标成「该车未装此模块，正确」。

### PE-55 ｜ 错帧 ID / 回帧头校验（E0 做法 + E1 抽样）
- **做法**：每步校验回帧 CAN ID 与请求 tx/rx 对应（DME `7E0/7E8`、网关 `710/77A`）；真车日志里探 `0x7F1/0x7F9` 却回帧头 `7E8` 属 ATSH 未落地的症状，应**当场报错不带着错地址往下跑**。多模块判源靠回帧 ID，不是靠请求顺序。
- **原始坐标**：`src/coder.js:422/697` 注释（探 0x7F1/0x7F9 回 7E8 症状）；E1 DME/网关捕获（`.local/x431-re/`，仅本机）；DME bench（`x431-dme-bench-2026-09-13.md`：`FC00`→0x7E0、`FD00`→0x7E8，SJA1000 11bit 打包假设）。
- **可复核命令**：`sed -n '418,425p;693,700p' /Users/se818/porsche-coder/src/coder.js`。
- **对应实现要求**：每次换模块重设 ATSH/ATCRA/ATFCSH；回帧 ID 不符即 fail-closed 报错；主链与广播链口径统一。
- **反例**：探 A 模块拿 B 模块的回帧当 A 的成功（串线假绿）。

## 8. 关键结论（闭合任务书指定缺口）

1. **真车正向应答只有 DME KWP 单模块不能泛化** —— 确证：E1 仅 14 款 Cayman 981 DME KWP；UDS/其他模块全链做法以 E0（静表+反编）为真值，E1 只抽样。四帧身份、10 03、seed/key、写的 E0 证据分别见 PE-20/10/30-32/40-41。
2. **seed/key「61.4% 无真值」已按 E0 拆解闭合** —— 非「待真车」：104 条 = 431 明确无 case → **不发 key 继续写入**（E0 明确行为，非缺口），4 条 mode 0x1D 依赖会话运行时全局态 `TOKEN+0x408838` → 名字分发兜底 / **fail-closed**（不猜 key），135 变体算法已入库 675/675 自检通过。写白名单按 E0 全集，不限 DME（PE-32）。
3. **7F78 是只续等不是重发** —— Set7F78Ctrl 控制器帧 + 包内无周期保活 + E1 9 条等待链三者一致（PE-50）。
4. **1A90 空值≠车型名** —— 车型名走 VIN→GetVehicleNameID（PE-22）。
5. **会话/KWP 老代** —— KWP 直接 10 89、UDS 流含 10 03、68 老代 sessionless 不发 10xx（PE-10/11/12），按 sysId 表选不按族选。

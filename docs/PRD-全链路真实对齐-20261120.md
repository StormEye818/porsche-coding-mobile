## 2. 证据等级与真值口径（核心新口径）

| 等级 | 定义 | 采信范围 |

**铁律（可证伪）**
- **G-1 可回溯**：任何摘要文档/JSON 字段必须能逐层回指到 431 原始包坐标 `<file>:<offset|VA|recordId>`；只有摘要、回指不到原始坐标的条目判为**无证据**。
- **G-2 无证据不实现**：任何一行实现（含兜底、默认值、常量、候选、超时、分支）无 E0 做法证据 → 不得写入运行时；填 `null`/猜一个值/沿用他代做法均判违规。
- **G-3 不泛化**：E1 真车日志不得外推为全代真值；「这台车测过」≠「全车型正确」。
- **G-4 禁用伪等价**：不再接受「符号命中=A」「做法看起来像=A」「全 NO DATA=车上没装」作为收口或结案理由；NO DATA 只能记为**待 E0 复核**。
- **G-5 证据边界分流**：每条 E2 产物必须带 `provable: static|runtime` 标记且以 E0 为准。**静态可证**（平台/type、模块清单、模块→sysId、变体零件号、车型数据集集合、请求键、帧模板）必须由 E0 坐标复算 diff=空；**不能静态独立证明**（请求键→CAN tx/rx 地址、trim 显示名、25 车型精确落定、逐候选探测成败、0x14/0x15/0x16 无路由 owner、编码扩展流）一律标 `runtime`，**请求键→CAN 的最终绑定/哪个候选是活地址只能由原生发现循环经 `showAddress("4000")` 上报获得（R 级机制，真值 R）**，上报不可用即 **fail-closed**；不得自创「连接期全段扫描 0x700–0x7FF/200ms 每地址」（该说法是 D 级我方设计，`431-linkmap` E-05/E-19 已证包内无此实现），不得静态写死 CAN 地址；把 runtime 项伪装成 static、把 D 级当 A 即违规。
